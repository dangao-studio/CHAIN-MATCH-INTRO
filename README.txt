【上傳到 GitHub Pages】
注意：不要放進你放遊戲的 CHAIN-MATCH 倉庫，裡面的 index.html 會被蓋掉，遊戲就壞了。

1. 登入 GitHub，右上角 + > New repository，名稱例如 chain-match-site，設為 Public，建立。
2. 在新倉庫按 Add file > Upload files，把 index.html 拖進去，按 Commit changes。
3. 到 Settings > Pages，Source 選 Deploy from a branch，Branch 選 main、資料夾選 / (root)，按 Save。
4. 等一兩分鐘，網址會是：
   https://dangao-studio.github.io/chain-match-site/

【想要更短的網址】
倉庫命名為 dangao-studio.github.io，網址就會是 https://dangao-studio.github.io/
